# Makepad SandStudio (MSS)

Makepad SandStudio is a Windows developer preview for running and observing independent hidden Makepad application instances. Desktop provides Human View tabs and the local MSS MCP provides AI Direct access to explicitly owned or shared App IDs.

The preview includes guest-native frame capture, viewport resize and addressed input for admitted RudraOffice builds, a read-only CAD view, Human View recordings with export privacy choices, and delivery of an approved recording to the installed Codex CLI. The profile catalog starts empty on a new machine. Bring an approved external guest build and its matching Makepad Remote. RudraOffice, AI CAD, experimental DWG worker, Python, PowerShell and Codex are external components.
