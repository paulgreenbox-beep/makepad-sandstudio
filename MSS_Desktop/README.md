# MSS Desktop

Human View displays native frames from independent hidden Makepad applications. Select a named tab to launch a configured profile. Use **Shared app** and **Find shared apps** to discover an instance made available by its owner. Attach by App ID. An attachment can be detached without closing the owner process.

For an admitted RudraOffice control attachment, the measured viewport resizes the selected guest. Click within the frame to direct input to the guest. CAD and read attachments remain view-only. AI Direct addresses the guest App ID independently of tab selection.

**Screenshot** saves the guest PNG. A Human View recording saves the addressed actions and optional frame and semantic observations. After stopping, select the data to include and click **Prepare for Codex**. Review the prepared files and description, then click **Send to Codex**. The installed CLI analyzes the approved package. A matching completed model receipt is required for `RECEIVED`.
